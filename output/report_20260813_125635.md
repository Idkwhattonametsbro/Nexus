## Key Assumptions

- **PostgreSQL 15** and **Redis 7** services for persistence and job queue.

- Multi‑tenant isolation is achieved via a `tenant_id` column on all tenant‑scoped tables and a request‑level `TenantContext` resolved from the sub‑domain.

### `README.md`
```markdown
# SaaSWeave – Full‑Stack TypeScript SaaS Starter

A production‑ready, multi‑tenant SaaS starter built as a **TypeScript monorepo**.  
It combines:

- **TanStack Start** – SSR React framework  
- **Hono** – lightweight HTTP server  
- **oRPC** – type‑safe remote procedure calls  
- **Drizzle ORM** – type‑first PostgreSQL queries  
- **Better Auth** – JWT + refresh token auth flow  
- **BullMQ** – Redis‑backed job queue  
- **Paraglide.js** – i18n with zero‑runtime overhead  
- **Docker Compose** – local dev & production stack  

## Quick Start

```bash
# Clone repo
git clone https://github.com/your‑username/saasweave.git
cd saasweave

# Install dependencies (pnpm)
pnpm install

# Start all services
docker compose up -d

# Run dev servers
pnpm dev   # uses Turborepo to start api & web
```

## apps/api/Dockerfile
```dockerfile
# ---- Builder ----
FROM node:20-alpine AS builder
WORKDIR /app
COPY ../../pnpm-lock.yaml ./
COPY ../../package.json ./
COPY ../../pnpm-workspace.yaml ./
COPY . .
RUN corepack enable && corepack prepare pnpm@9.1.0 --activate
RUN pnpm install --frozen-lockfile
RUN pnpm run build --filter=api

# ---- Runtime ----
FROM node:20-alpine AS runtime
WORKDIR /app
ENV NODE_ENV=production
COPY --from=builder /app/apps/api/dist ./dist
COPY --from=builder /app/package.json .
COPY --from=builder /app/pnpm-lock.yaml .
RUN corepack enable && corepack prepare pnpm@9.1.0 --activate && pnpm install --prod --frozen-lockfile
EXPOSE 4000
CMD ["node", "dist/index.js"]
```
